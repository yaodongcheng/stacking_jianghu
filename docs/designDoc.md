一、游戏概述
1.1 一句话概括
玩家因故家破人亡流落到一个小镇，初始一贫如洗，需要在小镇扎根，解决NPC的困难赢得支持，壮大势力，最终对抗仇敌。
1.2 核心玩法定义
AI小镇的核心卖点是AI驱动的动态叙事——NPC有自己的人设、事件由AI生成、剧情不重复。一个自然的想法是：既然AI是核心卖点，我们应该全力做AI叙事，让故事本身成为玩法。
这意味着两条路线：
路线做法代表产品A. 纯AI叙事流玩家和NPC自由对话，AI实时生成剧情走向，没有传统数值体系，体验类似互动小说/TRPGAI Dungeon、Character.AI角色扮演、部分AI视觉小说B. 数值经营 + AI叙事先有一套脱离AI也能玩的模拟经营/生存数值循环，AI在此之上让事件更丰富、叙事更自然我们选择的方向
我们选择路线B。以下是原因。
问题1：纯AI叙事没有数值锚点，选择就没有重量
纯叙事流中，玩家做一个选择——比如"帮老赵还是不帮"——后果是什么？是AI生成的一段文字告诉你"老赵很感激"或"老赵很失望"。
问题在于：玩家读完就忘了。因为这个"感激"或"失望"不会真正影响接下来的游戏体验。NPC说他恨你，但你下次还是能跟他对话，他也不会真的拿刀来砍你、真的让你买不到食物、真的让你在冬天冻死。
冰汽时代的选项之所以令人痛苦，不是因为文案写得好，而是因为选完之后你的煤炭真的少了500，你的人真的死了200个，你接下来的10分钟游戏体验真的变难了。
结论：没有数值系统承接后果的选项，只是阅读体验，不是游戏体验。
问题2：纯AI叙事流缺乏长期留存的钩子
互动叙事类产品有一个共同困境：玩家在新鲜感消退后没有理由继续玩。
AI Dungeon的用户数据、Character.AI的留存曲线都印证了这一点——玩家初次体验时惊叹"AI好厉害"，但一周后就觉得"也就那样"，因为没有进度感、没有成长感、没有"我还差一点就能达成某个目标"的牵引力。
模拟经营天然解决这个问题：
我的铜币从10攒到了500——成长感
我还差3个NPC就能凑齐对抗仇敌的团队——目标感
我这周的食物储备够了但是冬天快来了衣服还没着落——紧迫感
结论：数值系统提供持续的目标牵引力，是长期留存的基础设施。
因此最终的框架是
模拟经营 + AI驱动叙事 + 社交策略
模拟经营层（底层）：脱离AI也能独立运转的生存/经济/社交数值博弈
AI叙事层（上层）：AI基于当前世界状态动态生成事件，让叙事与机制统一
社交策略层（贯穿）：NPC关系网是核心资产，玩家通过选择经营这张网

1.3 参考作品
参考作品参考维度潜水员戴夫个体视角的日循环节奏：获取信息→准备资源→消耗验证冰汽时代2选项设计：多资源维度拉扯，没有全赢选项王权（Reigns）单次决策影响多个维度的滑动条，数值归零即死亡中国式家长NPC人生节点的"养成→爆发"叙事结构
举例说明一个冰汽时代2的选项设计，希望让玩家达成这样的纠结效果：
1、玩家刚进入游戏，目标是带领百姓们在寒冬中活下去。
2、系统会反复教育玩家以下事实：煤炭很重要，没有煤炭大家都会冻死；劳动力也很重要，没有劳动力就没人挖煤。社会舆论也很重要，如果做事情不让Npc满意就会降低信任值，信任值为0就会被赶下台。
3、经过多次游戏内部循环，玩家会认可上述规则，这是一个资源权衡游戏。
4、这时候刷新一个事件：煤矿内部着火，但是里面还有一些工人没出来。
选项A：封死煤矿，这样之后煤矿还有继续复用的可能。
后果：劳动力-200，之后可能会出现事件人们表达对执政官冷血的不满。
选项B：尽量把人救出来，但是煤矿以后就不能用了。
后果：劳动力-10，但是煤矿资源储备-1000，人们欢呼雀跃，但是你之后会面临资源不够用的危机，一样会引来玩家不满。
选项C：忽视不管（可能是最恶劣的后果）
这里之所以令人纠结，就是因为玩家非常认可劳动力、煤炭以及信任度这三个数值。

4.2 属性用途
4.2.1 生存压力
玩家每一天都面临数值自然流失的压力，必须主动行动来维持生存
三条命脉（生存线、经济线、声望线）任意一条崩溃都会导致游戏失败
4.2.2 事件选项解锁
事件选项的门槛直接读取能力属性和社交属性：
示例：
选项"以理服人"  → 门槛：智力 ≥ 25，与当事人好感 ≥ 20
选项"暴力解决"  → 门槛：力量 ≥ 30，
选项"偷偷解决"  → 门槛：敏捷 ≥ 20，
选项"花钱摆平"  → 门槛：铜币 ≥ 200
选项"找人帮忙"  → 门槛：与某NPC好感 ≥ 50，人情债余额 > 0
4.2.3 Npc行为
NPC对玩家的态度由好感度区间决定：
  好感 < -0  → 敌对：NPC可能主动找玩家麻烦、拒绝交易
  好感 10~70  → 友好：交易价格下调10+x%，偶尔主动提供情报
  好感 > 70   → 忠诚：可被招募为粉丝，愿意为玩家冒险

5.2 故事主线
初始，玩家流落到小镇上逃难，但是仇敌迟早会找上门来。随着游戏进程时间流逝和玩家的操作，仇敌对玩家的威胁度会逐渐上升：
威胁度 20 → 【节点1】镇上出现陌生人打听事情（信息层面）
威胁度 40 → 【节点2】仇敌的手下来镇上施压某NPC（间接冲突）
威胁度 60 → 【节点3】仇敌直接对玩家的盟友下手（正面冲突前奏）
威胁度 80 → 【节点4】仇敌亲自或派精锐来镇（最终对抗序幕）
威胁度 100 → 【终局】不可避免的决战
5.3 随机事件
玩家的游玩过程就是 解决事件 和 提升自我 中反复循环。在这个过程中玩家的能力会越来越强，粉丝团会越来越大，最终有实力直面恶人。
威胁度 < 20（平静期）：
  AI事件种子池=日常生活类（邻里纠纷、经济困难、情感问题）
  目的：让玩家熟悉镇子、建立关系、积累资源
├── 【蜜月】连续2-3天顺利事件，资源获取大于消耗
├── 【小波澜】1天出个小麻烦，考验玩家是否掌握了基础机制
└── 【暗示】1天出现一个看似无关但实则暗示仇敌存在的事件
威胁度 20~40（暗流期）：
  AI事件种子池 +=社会动荡类（有人被勒索、商路被截、流言四起）
  目的：让玩家感受到"外部势力在渗透"，这些事件表面是NPC的日常，
       但背后和仇敌势力的扩张有关联
├── 【暗流涌动】表面日常事件，但连续2-3天结果都指向同一个幕后势力
├── 【信任危机】某个你依赖的NPC突然态度转变，需要调查原因
└── 【意外收获】在压力中突然获得一个盟友或资源，缓解节奏
威胁度 40~60（风暴前）：
  AI事件种子池 +=站队抉择类（NPC被迫选边站、有人想叛变投敌）
  目的：玩家之前积累的社交关系开始被考验
├── 【站队风暴】连续事件迫使多个NPC表态，关系网剧烈重组
├── 【围城前夜】资源供给线被切断，需要紧急开辟替代方案
└── 【叛徒】一个高好感NPC被揭露/被胁迫背叛
威胁度 60+（正面对抗）：
  AI事件种子池 +=战争类（资源争夺、攻防、营救）
  目的：之前所有积累的资源、关系、能力全部进入"兑现"阶段
├── 【攻防战】资源大量消耗，盟友受伤/阵亡，每个选择都有重大代价
├── 【绝地反击】在极端劣势下出现一个高风险高回报的翻盘机会
└── 【决战】终局对抗，所有积累的关系和资源进入结算

5.4.1 AI导演监控信号

AI导演实质上是一个实时运行的"动态关卡设计器"，它持续监控以下玩家状态信号，据此调整叙事节奏：

| 监控维度 | 具体指标 | 数据来源 | 说明 |
|---------|---------|---------|------|
| 目标进度 | 主线威胁度、当前NPC人生节点阶段 | 威胁度系统、StoryDirector | 玩家离终局有多远 |
| 资源压力 | HP、饱食度、寒冷值、铜钱 | 角色属性系统 | 玩家当前的生存余量 |
| 事件密度 | 最近N天内触发的事件数量、事件间隔天数 | 事件历史日志 | 玩家经历了多少"大事" |
| 社交密度 | 玩家最近的NPC交互频次、好感变化幅度 | 社交关系系统 | 玩家的社交活跃度 |
| 情绪轨迹 | 最近5天的体验标签序列（顺利/纠结/挫败） | 情绪日志 | 连续挫败需要缓解 |
| 沉浸感指标 | 玩家主动闲聊频率、主动探索行为（如查看告示板、训练、交易） | 行为日志 | 玩家是否在主动参与世界 |

基于这些信号的综合评估（即"承压指数"），导演动态调整：
- **事件触发时机**：资源压力高+事件密度高 → 延后下一个事件，给喘息空间
- **冲突升降级**：连续顺利 → 加压升级；连续挫败 → 缓和降级
- **节奏留白**：事件密度过高时，主动插入"平静日"，让玩家有时间经营和准备
- **信息投放**：沉浸感低时，增加NPC主动搭话、告示板更新等引导；沉浸感高时，减少干预让玩家自由探索

5.4.2 导演干预的分寸感

导演干预的核心难题在于分寸——太强，玩家会觉得被"推着走"，丧失自主感；太弱，叙事可能失控，玩家不知道该做什么。

设计原则：
- 导演只调节**节奏和强度**，不决定**具体内容和结果**——"什么时候来事"由导演决定，"来什么事、怎么选"由AI叙事引擎和玩家决定
- 导演的调节对玩家**不可见**——玩家感受到的是"世界自然运转"，而非"被安排"
- **保护规则优先于施压冲动**：连续施压不超过3天，连续挫败后必须给正反馈机会
- 导演永远不会阻止玩家的自由行动，只会调整NPC和事件的反应强度
- 当玩家主动制造冲突（如挑衅NPC、偷窃）时，导演不干预后果——玩家选择的后果应如实兑现

导演不负责的事情：
- 不生成具体的对话内容（由AI叙事引擎负责）
- 不控制NPC的具体行为（由NPC行为系统/需求金字塔负责）
- 不决定事件的结局（由玩家选择+数值系统决定）

5.5 时间流逝与事件节奏

说节奏之前，先看看参考的对象：《潜水员戴夫》的玩法是一个优秀的基于个体视角的模拟经营框架，steam96%好评。

我们先来看潜水员戴夫是怎么设计不同天之间的游戏节奏的：
参考潜水员戴夫，我们可以这样设计事件游玩节奏
潜水员戴夫AI小镇来到寿司店打工上午：查看状态、获取信息夜晚触发事件，引导玩家潜水夜晚：事件触发，出现选择去潜水自由探索、搜集资源下午：工作赚钱、训练属性、探索小镇用资源卖寿司/解决事件夜晚：用资源应对事件选项（门槛/消耗）从邮件知道后面需要什么上午：NPC的话、公告栏、事件伏笔告诉你需要什么

**改造：12时辰时间流逝系统**

游戏采用12时辰制，时间自然流逝，玩家自由行动不受回合限制：

| 时辰 | 时间 | 时段特点 | 玩法倾向 |
|------|------|----------|---------|
| 子时 | 23:00-01:00 | 深夜 | 暗杀、潜入、夜间事件 |
| 丑时 | 01:00-03:00 | 凌晨 | 突发事件、秘密活动 |
| 寅时 | 03:00-05:00 | 黎明前 | NPC开始准备日常 |
| 卯时 | 05:00-07:00 | 清晨 | 势力任务发布、日常开始 |
| 辰时 | 07:00-09:00 | 早晨 | 情报委托触发、告示板更新 |
| 巳时 | 09:00-11:00 | 上午 | 社交活动、商业交易 |
| 午时 | 11:00-13:00 | 正午 | 事件高发期 |
| 未时 | 13:00-15:00 | 下午 | 自由行动、任务推进 |
| 申时 | 15:00-17:00 | 傍晚 | 事件触发、冲突爆发 |
| 酉时 | 17:00-19:00 | 黄昏 | 夜间活动准备 |
| 戌时 | 19:00-21:00 | 晚上 | 娱乐事件、秘密活动 |
| 亥时 | 21:00-23:00 | 入夜 | 势力活动、夜间任务 |

**核心变化**：
- 不再是"上午/下午/夜晚"三段式，而是连续的时间流逝
- 玩家可以随时做任何事，行动消耗时间
- 不同时辰有不同的事件触发概率和NPC活动规律
- 时间控制：正常速度/加速（休息/等待）/暂停（菜单/对话）

5.6 事件层次与线索系统

**核心循环：信息获取 → 资源准备 → 消耗验证**

为了解决"事件间隙无焦点"问题，引入**线索系统**作为连接事件与日常经营的桥梁：

```
┌─────────────────────────────────────────────────────────────┐
│                    玩家日常循环                               │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  【信息获取阶段】辰时-巳时（07:00-11:00）                      │
│  ├── 查看江湖告示板（公开情报、委托任务）                      │
│  ├── 与NPC闲聊（获取线索碎片）                                │
│  └── 接收情报委托（主动调查任务）                             │
│       ↓                                                      │
│  【资源准备阶段】午时-未时（11:00-15:00）                      │
│  ├── 根据线索提示，针对性提升能力                             │
│  │   例：线索提示"可能需要武力介入"→去训练力量               │
│  ├── 攒钱、收集道具、维护关系                                 │
│  └── 完成情报委托，获取完整情报                               │
│       ↓                                                      │
│  【消耗验证阶段】申时-戌时（15:00-21:00）                      │
│  ├── 事件触发（起承转合各幕）                                 │
│  ├── 用准备好的资源应对选项门槛/消耗                          │
│  └── 选择后果影响NPC命运和玩家关系网                          │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**事件层次结构**：

| 层次 | 定义 | 时间跨度 | 玩家角色 |
|-----|------|---------|---------|
| **Npc命运线** | NPC在小镇经历的完整命运轨迹 | 游戏全程 | 见证者/推动者 |
| **Npc人生节点** | NPC遇到的两难选择，需经历起承转合4幕 | 2-4天 | 关键影响者 |
| **起承转合幕** | 人生节点的具体阶段，每幕1个事件 | 1天 | 选择推动者 |
| **线索任务** | 幕前准备，收集信息、提升能力 | 幕前任意时间 | 主动准备者 |

**起承转合与线索的对应关系**：

| 阶段 | 核心冲突 | 线索作用 | 选项特点 |
|-----|---------|---------|---------|
| **起(EMERGE)** | 问题初现 | 预告"即将发生什么" | 3选项，试探性介入，成本低 |
| **承(ESCALATE)** | 矛盾升级 | 提示"需要准备什么" | 3选项，必须站队，有门槛 |
| **转(CLIMAX)** | 关键抉择 | 揭示"真相是什么" | 2选项，二选一，代价最高 |
| **合(SETTLE)** | 后果兑现 | 记录"发生了什么" | 2-3选项，善后处理 |

**关键设计原则**：

1. **每幕前必有线索**：AI导演在生成下一幕事件前，先生成线索任务
2. **线索即准备指引**：每条线索都暗示玩家应该提升什么能力/准备什么资源
3. **准备有回报**：根据线索做准备的玩家，在事件中获得更好选项或降低成本
4. **不准备也能玩**：没有准备的玩家仍能推进，但选择受限或代价更高

**选项设计结构**：

```
每个选项包含：
├── 文本描述（15-20字，[手段]具体做法）
├── 门槛（属性/道具/关系要求）
├── 消耗（付出代价）
├── 收益（获得回报）
├── 后果预览（即时反应+长远影响）
└── 张力变化（影响局势压力）
```

**CLIMAX阶段的特殊设计**：

- 基础2选项：desire vs misgiving（两难抉择）
- 解锁第3选项：通过前置准备（收集足够线索/与关键NPC关系好/拥有特定道具）
- 第3选项特点：高成本但可能"两全其美"，奖励有准备的玩家

**SETTLE阶段的设计原则**：

- 不能"撤销"转的选择，只能"面对"它
- 根据"转"的选择结果，提供不同的善后路径
- 确保重大选择有长期影响，不能被完全修复

看到这里，会发现核心问题在于，玩家得对游戏内的数值变动有强烈的感触，整个游戏循环才能成立。线索系统正是连接"日常经营"与"事件选择"的关键桥梁，让玩家知道"该准备什么"。

5.8 共享叙事记忆与感知过滤

5.8.1 世界事实库

5.8.2 感知过滤器

NPC在生成对话或决策行为前，会从世界事实库中查询信息，但查询结果需要经过**感知过滤器**——判断这个NPC是否有合理的途径知道这件事。

核心原则：**真实感不是来自NPC无所不知，而是来自他们"知道该知道的，不知道不该知道的"。**

| 感知途径 | 判定条件 | 信息质量 | 示例 |
|---------|---------|---------|------|
| 亲眼所见 | NPC在事件发生时处于同一地点 | 完全准确，细节丰富 | 张铁匠亲眼看到打手砸门，能描述人数、长相、说了什么 |
| 间接听闻 | NPC与知情者有社交关系（好感≥10），且近期（2天内）有过交流 | 基本事实准确，细节可能模糊或有偏差 | 李大婶听邻居说起赵掌柜被骚扰，知道"有人闹事"但不清楚具体经过 |
| 逻辑推断 | NPC智力≥30，且观察到相关结果或线索 | 推断可能正确也可能错误 | 药铺老板注意到张铁匠频繁来问药价，推断其家人病重（正确推断） |
| 公共知识 | 事件涟漪传播范围超过阈值（≥5个NPC知道） | 基本事实准确，动机和细节不清 | 全镇人都知道来了一群外地人，但不知道他们的目的 |

感知过滤的应用场景：
```
场景：玩家夜间暗中调查了青龙帮

NPC感知结果：
├── 张铁匠（亲眼所见：不适用，不在场）
│   → 不知道玩家去调查了
├── 夜间巡逻的王捕头（亲眼所见：看到玩家在码头附近徘徊）
│   → 知道玩家夜间行踪可疑，但不知道目的
├── 李大婶（间接听闻：第二天王捕头跟她提了一嘴）
│   → 知道"有人说你昨晚在码头那边晃"，细节模糊
├── 赵掌柜（无感知途径）
│   → 完全不知道
└── 青龙帮成员（逻辑推断：发现有人翻过他们的东西）
    → 知道"有人来查过"，但不确定是谁（除非有其他线索）
```

感知过滤与已有系统的关系：
- **与涟漪系统的配合**：涟漪系统负责"事件传播给了谁"（传播范围），感知过滤负责"NPC知道多少细节"（信息深度）。两者配合使用——涟漪系统输出受影响的NPC列表和态度变化，感知过滤器决定每个NPC在对话中能说出什么
- **与NPC行为系统的配合**：NPC的需求金字塔决定"想做什么"，感知过滤决定"基于什么信息做决策"。一个不知道外来威胁的NPC不会因此改变行为；知道了的NPC才会寻求保护
- **与AI叙事引擎的配合**：生成NPC对话时，将感知过滤后的信息注入LLM上下文，确保NPC不会说出自己不该知道的信息

NPC每日日程生成逻辑：

1. 扫描需求金字塔，找到最低未满足层
2. 根据该层需求选择行为：

   - 安全未满足 → 去找保护者/躲在家里/加入帮派
   - 归属未满足 → 去酒馆社交/找朋友/参加集会
   - 需求都满足 → 执行职业默认行为（农民种地、公子喝茶）

3. 在行为执行路径中，检查偶遇条件

七、结合了AI导演情绪控制思路的体验设计预想
用一个完整的3天流程，展示AI导演如何与已有系统协同工作：
Day 12 —— 游戏进行到第12天
日初 · AI导演宏观决策：
读取状态：
- 威胁度：32（暗流期，距离节点2的40还有8点）
- 玩家HP：75，饱食度：45，铜钱：180
- 忠诚NPC：2个（张铁匠 好感72，李大婶 好感68）
- 近5天情绪：[顺利, 纠结, 顺利, 顺利, 普通]

承压指数计算：
- 生存维度：0（HP和饱食度都OK）
- 经济维度：1（铜钱够3天但不宽裕）
- 社交维度：0（有忠诚NPC）
- 近期情绪：0（没有连续挫败）
承压指数 = 1 → 导演意图 = "施压"（玩家太舒服了）

八、目前Demo不足分析

Demo已完成内容：
单个Npc起承转合
简单的Npc行为
基础的Npc、资源、建筑、道具定义，
基础的卡牌堆叠功能，配表就可以生成几千种不同的配方，比如 Npc+树木=木材
问题 1：数值无感（根因）
玩家得对游戏内的数值变动有强烈的感触，整个游戏循环才能成立。
目前状态属性、能力属性、财富、社交关系定义都有了，但它们没有形成"不满足就会死"的压力闭环。冰汽时代之所以选项痛苦，是因为煤炭=0→全城冻死、劳动力=0→没人干活、信任=0→下台。你的小镇目前缺少等价的生存压力源。
玩家即使不触发事件，也必须每天想办法吃饭、赚钱、找地方住，这就是"脱离AI也能玩"的底层经营循环。
数值变化必须有即时的、夸张的UI反馈：
饱食度低于30%：屏幕边缘出现黑影，角色走路变慢
铜币不足时查看事件选项：被锁选项显示红色大锁+需要的铜币数
好感变化：NPC头顶弹出 ❤️+20 或 💔-40 的飘字，且NPC的表情/对话态度立刻变化
问题 2：事件间"真空期"
小镇在事件结束后，在下一个事件开始之前，玩家不知道下一步该攒什么、防什么。失去目标焦点，我应该去赚钱还是提升能力还是搞好人际关系？
参考潜水员戴夫的白天/夜晚天然制造了"信息获取→资源准备→消耗验证"的节奏。
问题 3：自由度与叙事一致性
比如牛二找玩家胡搅蛮缠，玩家完全可以找他的领导黑风大王投诉，无论黑风大王认可与否，后面这件事情都应该在剧情中体现。但是目前这一块还没有融合的很好。
优先级判断
问题1 >=  问题2 > 问题3
数值无感是地基问题，地基不稳，再好的叙事也撑不住循环。
问题2是中层框架。
问题3是上层自由度，可以在前两层稳固后再做。
