## 第2页：核心问题

### 布局

- 页面上半部分是一句大字提问，占据约40%页面高度，居中
- 问题文字白色，关键动词用橙色高亮

### 内容

```
大字：
当"挑战物"
从一个可被【打败】的实体，
或一个可被【解决】的结构，
变成一个动态的【社会系统】时——

游戏设计的底层范式，需要怎么变？
```

### 演讲稿

> 我们做游戏设计这么多年，已经非常擅长设计两类挑战。第一类：一个可以被打败的实体——Boss。第二类：一个可以被解决的结构——谜题、关卡、开放世界的探索目标。我们有成熟的理论、成熟的工具、成熟的设计语言来处理它们。但现在，AI技术让第三种挑战成为可能——一群有自己性格、立场、关系网络的人。他们不是用来打败的，也不是用来"解开"的。那他们是什么？玩家面对他们的时候，"赢"是什么意思？"玩"是什么意思？如果我们回答不了这个问题，所谓的AI原生游戏就永远只是一个技术demo。

### 演讲稿

> 答案来了。当挑战是"一群人"时，胜利条件的本质是——改变一个社会系统的状态。你看屏幕上这两张图。左边是初始的人际关系网络，有些人互相信任，有些人互相敌对，有些人互不相干。右边是目标状态——经过你的介入，某些关系被建立了，某些联盟被打破了，某些人的立场翻转了。你不是在"打败"这群人，也不是在"走过"他们，你是在改变他们之间的关系和立场，最终让整个系统到达一个你需要的状态。这就是"社会系统挑战"的胜利条件。

## 第8页：准则1——心流

### 布局

- 页面标题 + 准则编号在顶部
- 页面分为上下两半
- 上半部分是一个经典的"心流通道图"（难度 vs 技能的坐标轴，中间一条通道，上方焦虑，下方无聊），但坐标轴的标注被替换为社会系统语境的内容
- 下半部分分左右两栏："上手层（任何人都能做到的事）"和"精通层（高手才能做到的事）"，各列3-4条

### 内容

```
页面标题：准则1 · 心流——易于上手，难于精通

[心流通道图]
X轴：玩家的社交策略能力
Y轴：社会系统的复杂度与抵抗力

【上手层】
· 任何人都能和NPC交谈
· 完成简单的请求与帮助
· 感知到小镇里"有事在发生"
· 表层任务是清晰的：有人求助、有人可疑、有人在吵架

【精通层】
· 理解NPC之间的隐性关系网络（谁是谁的把柄，谁欠了谁人情）
· 理解"信息作为资源"——知道什么、什么时候说、对谁说
· 理解时机——NPC刚和别人吵完架时去拉拢，效果完全不同
· 理解二阶效应——你帮了A，B会怎么看你？
```

### 演讲稿

> 第一条，心流。Csikszentmihalyi的心流理论告诉我们，挑战难度必须和玩家能力匹配。在Boss战里，这靠操作难度调节。在社会系统里，调节的是什么？上手层非常自然——你看到有人在哭，你走过去问怎么了，她告诉你她的猫丢了，你帮她找。这谁都能做。但精通层的深度是惊人的。当你开始理解：这个人表面上在找猫，其实是在借此事试探我是否值得信任；而隔壁那个人盯着我和她的对话，因为他们俩有旧怨——当你开始读到这一层的时候，策略空间突然炸开了。注意，这种深度不亚于动作游戏的操作深度，但维度完全不同。它是认知维度的深度。

### 内容

```
页面标题：准则2 · 松弛节奏——控制"戏剧张力密度"

[波形对比图]
上：L4D2 → 控制"威胁密度"
下：社会系统 → 控制"戏剧张力密度"

【紧张时刻】

```

### 演讲稿

> 第二条，节奏。Left 4 Dead 2的导演系统是游戏设计史上的里程碑——它实时监控玩家的压力水平，动态调节僵尸刷新密度，创造出一张一弛的呼吸感。在社会系统中，我们控制的不是僵尸数量，而是戏剧张力。紧张时刻是什么？是你精心编织的谎言马上要被第三个人戳穿的那一刻。是两个你都需要的人正在决裂、你必须选边站的那一刻。松弛时刻呢？是你在酒馆角落喝着酒，安静地听两个NPC聊天，从中捕捉到一条你之前不知道的信息线索。是你打开笔记本，看着关系图谱，规划下一步行动。一张一弛，这才是节奏。实现手段包括事件调度、紧迫性分级、以及安全区设计——有些NPC或场所是"避风港"，让玩家可以喘息和复盘。

## 第10页：准则3——反馈感知

### 布局

- 页面标题顶部
- 页面主体分左右两大块
- 左侧标题"Boss战的反馈"，列出3条，配以简单的icon（血条图标、动画变化图标、受伤特效图标）
- 右侧标题"社会系统的反馈"，列出对应的3大类，每类下有2-3条具体说明
- 左右之间用虚线箭头"→"连接对应项，表示映射关系
- 底部用红色警告框放一句关键原则

### 内容

```
页面标题：准则3 · 反馈——最容易出问题的环节

【Boss战的反馈】                    【社会系统的反馈】
① 血条变化           →    ① NPC可观察的行为变化
                              · 信任你后：主动找你、当众为你说话、开门让你进入
                              · 不信任：回避视线、在你接近时转身、向他人耳语
                              · 被激怒：公开指责、向权力人物告状、联合排斥你

② Boss阶段转换动画    →    ② 系统层面的状态指示
                              · 关系网络图谱可查看
                              · NPC态度指示器（表情/颜色/肢体语言，非精确数值）
                              · 信息面板：你已经知道了什么，还有什么矛盾与空白

③ 受伤 = 明确惩罚    →    ③ 失败后果具体、可感知、通常非Game Over
                              · 惹恼关键人物 → 路径被封，但需要绕路，不是死局
                              · 信息泄露 → NPC行为模式改变，计划需要调整
                              · 最严重：社会系统进入不可逆的坏结局锁定

⚠ 核心原则：
"成功"不是NPC说了"谢谢"，
而是NPC的行为、态度、社会网络拓扑
发生了你预期方向的变化。
```

### 演讲稿

> 第三条，反馈。这是最容易出问题的地方，也是现有AI对话游戏几乎全军覆没的地方。问题出在哪？你跟一个NPC说了一句话，NPC回了一句话。你完全不知道这次交互是成功还是失败。没有反馈，就没有学习，没有学习，就没有心流，没有心流，就不是游戏。看左边Boss战的反馈多么直观——血条在掉、Boss进入第二阶段开始发光、你被打了屏幕抖动变红。每一帧你都知道自己的处境。右边，社会系统需要同等清晰的反馈。第一层，NPC的行为要变化，不只是台词变化——信任你的人会走过来主动找你，不信任你的人看到你会转身走掉。第二层，系统要给你工具来追踪进展——关系图谱、态度指示器、信息面板。第三层，失败的后果要具体可感知，但通常不应该是Game Over。路被封了，但还有别的路。底部这句话请记住——成功不是NPC说了"谢谢"，而是社会网络发生了你预期方向的结构性变化。

## 第11页：准则4——多路径无最优解

### 布局

- 页面标题顶部
- 主体是一个"策略空间"对比表，左列Boss战，右列社会系统，4行
- 下方用一个"成本-副作用"矩阵来说明"无最优解"的保证机制：横轴是4种策略手段（诚实、欺骗、利益交换、情感投入），纵轴是效率/风险/长期代价，用颜色编码（绿=好，红=差，黄=中）形成一个棋盘格式的矩阵，没有任何一列全绿

### 内容

```
页面标题：准则4 · 多路径——每种策略都有成本和副作用

【策略空间对比】
                Boss战                    社会系统
维度1     武器/技能选择              信息路径：先了解谁？从谁口中打听？
维度2     走位/站位                  关系路径：拉拢谁？放弃谁？对抗谁？
维度3     攻防节奏                  手段光谱：诚实/欺骗/施压/示弱/借力
维度4     道具/消耗品使用            时序：先A后B ≠ 先B后A

【无最优解的保证：成本-副作用矩阵】
              诚实    欺骗    利益交换    情感投入
短期效率       中      高        高          低
被识破风险     无      高        低          无
长期社会资本   高      负        中          高
时间消耗       高      低        中          极高

→ 没有一列全是绿色。每种策略都有代价。
```

### 演讲稿

> 第四条，多路径无最优解。在Boss战里，策略多样性来自武器、技能、走位、道具的组合。在社会系统里，策略多样性来自四个维度——信息路径、关系路径、手段光谱、行动时序。看下面这个矩阵。诚实，长期回报高，但短期效率低、耗时长。欺骗，短期效率最高，但有被拆穿的风险，一旦拆穿你的社会资本直接归零。利益交换，高效但需要资源且不建立真正的忠诚。情感投入，回报稳固但极其耗时。注意，没有任何一列全是绿色。这就是"无最优解"的底层保证——不是靠设计师人为设置路障，而是系统本身的成本结构就不允许最优解存在。玩家必须根据自己的处境、时间压力和风险偏好做出取舍。这才是策略深度的来源。

```
页面标题：社交是核心，但不是全部——它必须嵌入更大的循环

  ↑ 信任建立 ↑
```

## 第15页：章节过渡页——AI的正确定位

### 布局

- 全页深色背景
- 上方一个大大的 ✗ 号（红色），旁边写错误定位
- 下方一个大大的 ✓ 号（绿色），旁边写正确定位
- 两者之间用一条明显的分割线

### 内容

```
✗ AI = 无限内容生成器
  "AI可以说任何话" → 这是Bug，不是Feature

────────────────────────────

✓ AI = 受约束的反应性挑战系统
  "AI在设计师定义的规则空间内，
   以远超脚本的灵活度响应玩家的策略"
```

### 演讲稿

> 现在进入最后一个关键问题：AI到底应该在这个框架里扮演什么角色？先说错的。把AI当成无限对话生成器——这是目前99%的AI游戏项目在做的事。NPC可以聊任何话题，回应任何输入。听起来很酷对吧？但这意味着没有边界，没有游戏性，玩家本质上在做的事情是"破解prompt"而不是"玩游戏"。"AI可以说任何话"不是Feature，是Bug。正确的定位在下面——AI是一个"受约束的反应性挑战系统"。它在设计师精心定义的规则空间内运作，但在这个空间内，它比任何脚本系统都灵活百倍。设计师定义边界，AI填充生命力。

## 第16页：AI原生游戏的三层架构

### 内容

```
│  · 世界设定与社会结构（固定）                      │
```

## 第17页：四条关键设计原则

### 布局

- 页面标题顶部
- 主体分为四个等大的卡片，2×2网格排列
- 每个卡片有一个编号、一个原则标题、2-3行说明
- 卡片用不同深浅的底色区分

### 内容

```
页面标题：四条关键设计原则

【1. AI不生产游戏性，设计师生产游戏性】
AI生产表现力和灵活性。
✗ 让AI决定NPC会不会被说服 → 玩家在"破解prompt"
✓ 设计师定义说服条件，AI决定NPC被说服时怎么表现

【2. AI的输出必须被系统"收束"】
每次AI响应 = 表现层（对话/行为）+ 状态层（数值/标记变更）
确保AI不会"飘走"，AI是有表现力的接口，背后是严格的系统

【3. 对话不是唯一甚至不是主要交互方式】
AI同样驱动：NPC行为决策、环境叙事生成、对玩家非对话行为的响应
NPC能"看懂"你做了什么，而不只是"听懂"你说了什么

【4. 涌现必须在设计空间内涌现】
NPC行为空间有限、状态空间有限
AI的自由度在于：在有限空间内，以怎样的路径和表现力来迁移
有方向的涌现 ≠ 无方向的模拟
```

### 演讲稿

> 四条原则快速过一遍。第一条：AI不生产游戏性。什么意思？说服一个NPC需要什么条件——需要你持有某个情报、且这个NPC的信任度大于60、且另一个关键NPC已经改变了立场——这些是设计师定义的。AI做的事情是：当这些条件被满足的时候，让这个NPC的反应是鲜活的、有性格的、有感情的。条件没满足呢？AI让NPC的拒绝也是有性格的、有逻辑的、甚至能暗示玩家还缺什么。第二条：AI的输出必须被收束。技术上来说，AI的每次响应必须同时输出一个结构化的状态变更指令，后台系统据此更新游戏状态。这是防止AI幻觉破坏游戏性的最核心的机制。第三条：别让AI只负责聊天。NPC看到你在夜里鬼鬼祟祟地从某个人家里出来——AI应该让这个NPC产生怀疑并且改变对你的行为，而不需要你跟他"聊"这件事。第四条：涌现必须有方向。斯坦福小镇实验很酷，但没人想"玩"它，因为那种涌现是无方向的、没有游戏性的。我们要的是有边界、有方向的涌现。

### 演讲稿

> 最后一页，把所有理论落成一个最小可行的设计。《水井镇》。你是一个外来者，到了一个中世纪小镇，发现三天后镇上要处决一个被指控为女巫的女人。你相信她是无辜的。你的终极目标是阻止这场私刑。但你一个人打不过全镇人，而且你是外来者，说什么都没人信。你必须在三天内，通过影响关键人物、收集证据、操控信息流动、建立自己的信誉，来改变这个社会系统的走向。阶段性目标是清晰的——说服镇长推迟审判、找到真相、拉拢盟友、瓦解指控者。微观操作是丰富的——今天下午你只剩6个小时，你是去酒馆打听情报，还是去牢房看望被告获取线索，还是帮铁匠干活建立信任？每一个选择都有成本、有风险、有你预见不到的连锁反应。
>
> 你看，我们刚才建立的所有理论——三层目标结构、心流、节奏、反馈、多路径、可读性、AI的约束架构——全部可以在这一个设计里找到落点。
>
> 这就是我今天想分享的核心观点：AI原生游戏不是伪命题，但前提是我们要先回答清楚那个最基本的设计问题——当挑战是"一群人"时，游戏性从哪里来？答案不在AI技术的能力清单里，答案在游戏设计的底层原理里。技术提供可能性，设计提供游戏性。当挑战是"一群人"，游戏才刚刚开始。谢谢大家。
