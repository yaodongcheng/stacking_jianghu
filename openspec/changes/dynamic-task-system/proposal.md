## Why

当前游戏存在两个核心问题：

**问题1：事件间真空期**
- 事件结束后、下一个事件开始前，玩家不知道该攒什么、防什么
- 失去目标焦点：应该去赚钱、提升能力、还是搞好人际关系？

**问题2：预告信息被浪费**
- 设计Doc里的"上午获取信息"环节（公告栏、NPC闲聊）已经能告知玩家"接下来要发生什么"
- 但这些信息是"被动阅读"，玩家看完就走，没有转化为行动目标

**解决方案：情报转化为NPC委托**

将预告信息转化为NPC委托玩家去搜集情报的任务形式：
- NPC说："最近有人在打听你的事，你能帮我问问张铁匠那人长什么样吗？"
- 玩家通过和其他NPC闲聊获取线索
- 闲聊本身就是玩法，推动社交系统使用
- 信息收集完成后，玩家知道"接下来要准备什么"

## What Changes

- **情报委托任务**：NPC基于预告信息主动委托玩家去搜集情报
- **闲聊线索系统**：NPC闲聊对话中可以提供任务所需线索
- **生存自发布任务**：玩家状态触发的生存任务（饿了/冷了/没钱了）
- **任务目标面板**：展示当前委托和进度

## Capabilities

### New Capabilities

- `info-quest-system`: 情报委托系统，NPC委托玩家搜集信息，通过闲聊获取线索
- `survival-task-system`: 生存任务系统，玩家状态触发的自动任务

### Modified Capabilities

- `npc-chat-system`: NPC闲聊系统，增加提供任务线索的能力
- `goal-panel`: 目标面板，展示当前任务和进度

## Impact

**核心影响范围**：
- AI导演系统：预告信息需要能转化为NPC委托
- NPC闲聊系统：需要支持线索提供
- 现有任务系统：在 QuestManager 基础上扩展

**设计约束**：
- 任务必须有明确的NPC发布人
- 情报委托的主目的是"让玩家知道接下来要发生什么"
- 存任务不是为了变成"任务清单游戏"，而是指引玩家行动
